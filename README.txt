VIVENA BIRTHDAY WEBSITE

HOW TO ADD YOUR 7 PHOTOS LATER:
1. Open the images folder in this website.
2. Upload your seven photos to that folder in GitHub.
3. Rename them exactly:
   photo1.jpg
   photo2.jpg
   photo3.jpg
   photo4.jpg
   photo5.jpg
   photo6.jpg
   photo7.jpg
4. If your photos are PNG, either convert them to JPG or update the image filenames in index.html.
5. Enable GitHub Pages from the repository Settings > Pages.

FILES:
- index.html
- style.css
- script.js
- images/ (add your photos here)

The website uses a normal, readable font and is designed for mobile screens.
